Selling the same item in different sizes, quantities, colours, styles or combos? Create ONE Parent listing (the cover buyers see first), then a Child listing for each variation — every child keeps its own title, own images, own price & stock. Buyers browse them all on one page.
🤔 Which one do I use? For one product in different colours / sizes / materials (like a T-shirt), you don’t need a Family — just leave this on “Standalone product” and use ③b Product Variations → 🧩 Combine below. Use a Family only when each variation should be its own separate listing with its own title & photos. Don’t use both for the same product. Need help? Tap 💬 Listing help.
Add unlimited variation types (Size, Color, Pack, Weight…) — each with unlimited options, individual pricing, an optional photo per option (📷 column) that buyers see when they pick it, and an optional package size per option (📦) for options that ship in a different-sized box.
💡 Example: Add a "Size" type with S, M, L options. Add a "Color" type with White, Black, Navy Blue. Each option can have its own Price, MRP and Stock.
